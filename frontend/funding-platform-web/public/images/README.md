# Home hero

`home-impact-hero.jpg` is a decorative, AI-generated photograph for the public home.
It is not a photograph of a real project or an endorsement by the depicted person.
Generated with the built-in image generation tool using the user's supplied home mockup
as a composition/mood reference. The existing vector brand and map are reused separately.
JPEG conversion only optimizes delivery; the original image was left unchanged.

Prompt:

> Use case: photorealistic-natural. Asset type: photographic website hero BACKGROUND ONLY,
> wide panoramic 3:1 landscape. Image 1 is a reference for composition and photographic
> mood, NOT a UI to reproduce. Generate a clean photograph inspired by only its top hero
> photograph: an adult woman viewed from behind on the far right, dark braided hair,
> textured earth-brown woven sweater and simple woven shoulder bag, looking across a
> sunlit Andean lake and layered mountains with natural vegetation. Keep the woman
> entirely in the rightmost quarter of the frame; show head and shoulders with breathing
> space above her head. The left two thirds should be open softly hazy pale sky, distant
> mountains and lake, suitable for dark HTML text over a translucent white gradient added
> separately by code. Warm soft natural afternoon light, authentic fabric and hair texture,
> quiet hopeful documentary photography, muted teal-blue water and mountains, not
> oversaturated. Absolutely no text, lettering, UI, buttons, cards, maps, logos, borders,
> watermark or interface elements. Deliver only the full-bleed photograph.
