# Editorial cover library

Four generic paper-cut thematic illustrations, generated with the built-in image
generation tool on 2026-09-21. They are not photographs of real projects, logos,
evidence of funding eligibility or endorsements. No external images are fetched.
Original generated PNG files are retained in Codex's generated_images directory;
these JPEG copies are resized to a 1200 px long edge and encoded at quality 82
for web delivery. Versioned keys must never be reassigned to unrelated artwork.

## Final prompts (one independent generation per asset)
