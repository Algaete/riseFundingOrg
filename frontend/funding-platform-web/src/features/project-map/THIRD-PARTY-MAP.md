# Natural Earth land geometry

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
Retrieved 2026-09-09. 1:110m land polygons, simplified locally at 0.5 degrees and projected
equirectangularly into a 720×360 SVG. Land only: no political boundary claims.

Public domain: https://www.naturalearthdata.com/about/terms-of-use/
The basemap is approximate and not for navigation. No runtime tiles, geocoding, API keys or
third-party requests. Project coordinates are supplied solely by the platform’s public API.
